      Method & code

      How the database is built

      Thirteen R scripts, run in order by run_all.R. Every cancer type goes through the same steps. Inputs are fetched automatically from UCSC Xena and the CELLxGENE Gene Expression API and cached, so re-runs only fetch what is new. The whole folder is pancancer_pipeline/; this page can't hand out files, so ask the page owner for it.

      Run it

      Install the packages once, in R
      install.packages(c("data.table", "ggplot2", "ggrepel", "patchwork", "pROC",
                   "R.utils", "jsonlite", "httr2", "RSQLite", "BiocManager"))
BiocManager::install(c("limma", "edgeR"))
      Everything, from the pipeline folder
      Rscript run_all.R
      Only some cancer types
      CANCERS=LUAD,BRCA Rscript run_all.R

      The first run downloads 1.3 GB from UCSC Xena, writes an 8.2 GB plain copy of the counts, and takes about 30 minutes. Later runs skip finished cancer types and reuse the CELLxGENE cache. Set REBUILD=1 to redo everything.

      The database

      Step 11 stacks every cancer type into results/database/, as CSV files and as one SQLite file, protease_pancancer.sqlite. Each table has a cancer column.

      Example query, in R
      db <- DBI::dbConnect(RSQLite::SQLite(), "results/database/protease_pancancer.sqlite")
DBI::dbGetQuery(db, "SELECT cancer, lfc_pooled, rank_by_effect
                     FROM nomination WHERE symbol = 'MMP11'
                     ORDER BY lfc_pooled DESC")

      Adding or fixing a cancer type

      Each cancer type is one row of config/cancer_types.csv: which TCGA label, which GTEx tissues, and which CELLxGENE tissue and disease ids. Edit a row and re-run with CANCERS=CODE REBUILD=1.

      Known limitations
      
      
        
        
      • AUCs are in-sample. The genes were chosen on the same samples, so treat AUCs as an upper bound until tested in an independent cohort.
        • 
        
      • One normal group is weaker evidence. Without the second arm, tissue handling (postmortem GTEx vs surgical TCGA) cannot be separated from tumour biology.
        • 
        
      • Normal tissue is sometimes approximate: whole blood for AML, ovary for serous ovarian cancer, transverse colon for rectal cancer. The cancer view lists each case.
        • 
        
      • Confounders are not modelled. Only sex is in the model; smoking, age and purity are not.
        • 
        
      • The single-cell data is aggregated and comes from whichever studies CELLxGENE holds for that tissue, so groups may differ by study. There are no per-donor confidence intervals.
        • 
        
      • The CELLxGENE API is not formally documented. If it changes, step 07 needs updating. Each cancer view shows the data snapshot used.
